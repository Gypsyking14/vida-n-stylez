# Vida N Stylez - Official Website

Live fashion portfolio + booking site for Vida N Stylez, Enugu, Nigeria.
Motto: beautiful and timeless pieces
Tagline: SLAY Effortlessly with our OUTFITS

## Features
- Full catalog with all designs (Native, Owambe, Party, Corporate, Couple)
- Filterable portfolio
- Bespoke Portal mockup
- Book appointment via WhatsApp + Paystack
- Business flow diagram

## Deploy to GitHub Pages
1. Create new repo on github.com named vida-n-stylez
2. Upload all files from this folder
3. Go to Settings > Pages > Source: Deploy from branch main / root
4. Your site will be live at https://YOUR_USERNAME.github.io/vida-n-stylez/
